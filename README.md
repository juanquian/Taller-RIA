# Instalación del proyecto

## 1. Clonar el repositorio

Abrir una terminal y ejecutar:

```bash
git clone https://github.com/juanquian/Taller-RIA.git

2. Entrar a la carpeta del proyecto
cd Taller-RIA/media-explorer

3. Instalar las dependencias
npm install

4. Iniciar el servidor de desarrollo
npm run dev

5. Abrir la aplicación
Después de ejecutar el comando anterior, la terminal mostrará una URL similar a esta:
http://localhost:5173
Abrir esa dirección en el navegador.

Requisitos previos
Antes de ejecutar el proyecto, la computadora debe tener instalado:
- Node.js
- npm
- Git

Para verificar si están instalados:
node -v
npm -v
git --version
